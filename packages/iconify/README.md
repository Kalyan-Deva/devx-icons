# @kalyan-dev/devx-icons-iconify

DevX Icons as Iconify JSON icon sets, for Iconify, UnoCSS (`preset-icons`), Tailwind plugins and anything else that reads Iconify JSON.

| Prefix | Style |
|---|---|
| `devx` | line, regular (1.75) |
| `devx-thin` · `devx-light` · `devx-bold` | line weights |
| `devx-solid` | solid |
| `devx-duotone` | line over an accent tint |
| `devx-bulk` | faded body, full accent |

Files: `json/<prefix>.json`. Accent colour follows `--devx-accent` (falls back to `currentColor`).
